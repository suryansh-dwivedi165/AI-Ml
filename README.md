## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/suryansh-dwivedi165/ai-ml-projects.git
```

Navigate to the project

```bash
cd ai-ml-projects
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Jupyter Notebook

```bash
jupyter notebook
```
